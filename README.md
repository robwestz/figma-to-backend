# figma-to-backend

A tool to convert Figma designs to backend code.

## Quick Start

For a comprehensive setup guide with IntelliJ IDEA Ultimate, see **[SETUP.md](SETUP.md)**.

### TL;DR - Get Started in 2 Minutes

```bash
# Clone the repository
git clone https://github.com/robwestz/figma-to-backend.git
cd figma-to-backend

# Open in IntelliJ IDEA Ultimate
idea .

# Or open manually: File → Open → Select figma-to-backend directory
```

Then follow the **[SETUP.md](SETUP.md)** guide to configure your IDE and start building.
