# Quick Start - IntelliJ IDEA Ultimate

## 🚀 Setup in 30 Seconds

```bash
# 1. Clone
git clone https://github.com/robwestz/figma-to-backend.git
cd figma-to-backend

# 2. Open in IntelliJ
idea .
```

That's it! IntelliJ IDEA Ultimate will handle the rest.

## 📝 Essential Commands

### First Time Setup
```bash
# If Node.js project:
npm install

# If Python project:
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Daily Development
```bash
# Run the application
npm start          # or: python main.py

# Run tests
npm test           # or: pytest

# Run linter
npm run lint       # or: flake8 .

# Build
npm run build      # or: python setup.py build
```

## 🔧 Common Issues

**Can't run code?**
→ Configure interpreter: `File → Settings → [Language] Interpreter`

**Slow?**
→ Exclude folders: Right-click `node_modules`/`dist` → Mark Directory as → Excluded

**Git not working?**
→ Enable: `File → Settings → Version Control → Enable Version Control`
